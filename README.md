# 🍽️ ZOMATO RESTAURANT ANALYSIS

### 📊 Data Analytics Project | Python | SQL | Excel | Power BI


## 📌 Project Overview

This project focuses on analyzing Zomato restaurant data to discover meaningful business insights about restaurants, customer ratings, cuisines, pricing, and locations.

The main objective is to transform raw restaurant data into meaningful insights using different Data Analytics tools.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Python | Data Analysis |
| SQL | Data Querying |
| Excel | Data Cleaning |
| Power BI | Dashboard & Visualization |
| Jupyter Notebook | Python Analysis |

## 📂 Project Files

1. **Python Notebook** – Data Analysis
2. **SQL File** – SQL Queries
3. **Cleaned Dataset** – Excel Dataset
4. **Executive Summary** – Project Insights
5. **Power BI Dashboard** – Data Visualization

## 🔍 Key Analysis

- Restaurant Ratings Analysis
- City-wise Restaurant Analysis
- Top Cuisines Analysis
- Restaurant Distribution
- Customer Preferences
- Pricing Analysis

## 🎯 Project Objective

To analyze Zomato restaurant data and identify useful business insights that can help understand restaurant performance, customer preferences, and food industry trends.

## 📈 Key Learnings

- Data Cleaning and Data Preprocessing
- Exploratory Data Analysis (EDA)
- SQL Query Writing
- Data Visualization
- Business Insight Generation
